# Module 1 — Anatomy of a custom assistant

**Slug:** `m01-anatomy-of-assistant`  
**Course:** Custom GPTs & Team Assistants  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Map the surfaces of a shareable assistant—instructions, knowledge, actions, starters, and sharing—so you stop treating a Custom GPT like a longer chat prompt.

## Why this module ships here

Teams fail when they paste a prompt into a custom shell and call it done. Module 1 names every dial you can turn before writing a novel instruction file.

## Success criteria for the learner

- Can contrast chat, custom assistant, and agent for an Acme Ops task
- Can name the five surfaces and what each is for
- Can write discovery cues (name, icon brief, short description) that set expectations
- Can kill a bad assistant idea before building it
