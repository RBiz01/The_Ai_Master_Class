## Teaching

### The Monday-morning problem

At **Acme Ops**, teams want automation that doesn’t just chat—it **researches, decides, and acts**. This lesson locks the skill you’ll reuse all week.

### Beat 1

No-code shines for deterministic if-this-then-that across SaaS.

### Beat 2

Agents shine when language understanding or fuzzy research is needed.

### Beat 3

Hybrid: workflow triggers agent for the fuzzy middle, then resumes steps.

### Talk-over narration (instructor VO)

*(Beat 1)*  
“No-code shines for deterministic if-this-then-that across SaaS.…”

*(Beat 2)*

“You’re done with this lesson when you can apply this on an Acme Ops scenario without guessing.”

## Worked micro-example

**Before**

> Agent renames every Drive file nightly.

**After**

> No-code rename rules; agent only for ambiguous customer intents.
