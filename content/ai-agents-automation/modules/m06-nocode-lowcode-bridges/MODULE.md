# Module 6 — No-code and low-code automation bridges

**Slug:** `m06-nocode-lowcode-bridges`  
**Course:** AI Agents & Automation Bootcamp  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

## Goal

Bridge LLM agents to Zapier/Make/n8n-style tools with triggers, webhooks, queues, and citizen-automation governance.

## Why this module ships here

Most companies already automate in no-code. Agents must plug in without shadow IT chaos.
