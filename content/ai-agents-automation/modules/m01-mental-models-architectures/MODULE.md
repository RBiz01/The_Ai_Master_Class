# Module 1 — Agent mental models & architectures

**Slug:** `m01-mental-models-architectures`  
**Course:** AI Agents & Automation Bootcamp  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Install a durable mental model for agents: sense → plan → act → observe, plus when chatbots, workflows, or multi-agent graphs are the right shape.

## Why this module ships here

Tool lists and frameworks fail without a clear architecture. Module 1 is the operating system for every later module.
