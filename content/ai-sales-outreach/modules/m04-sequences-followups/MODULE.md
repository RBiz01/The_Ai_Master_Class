**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

## Goal

Design multi-touch sequences with value-first cadence, breakup/re-engage moves, and reply branches that stay human.

## Why this module ships here

Sequences fail when every touch is ‘just bumping.’ Module 4 installs architecture, value, and graceful exits.

## Success criteria for the learner

- Can sketch a 5–7 touch sequence with purpose per touch  
- Can write a follow-up that adds value, not guilt  
- Can draft a breakup and a re-engage that feel respectful  
- Can branch on reply types (busy / not now / interested)
