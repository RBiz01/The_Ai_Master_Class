## Who this is for

Marketers, founders, designers, and creative operators who need **brand-consistent stills**—photoreal, stylized, and campaign-ready—without booking a studio every week.

Differentiator: this is **stills only** and goes deeper on lock, consistency, edit, and brand kit than the survey-style `generative-media` course (image + video overview).

No coding required. Patterns are **model-agnostic** (Midjourney / Flux / SD-style). Scenarios use fictional **Northstar Studio** and `learner@example.com` only.

## Learning outcomes

By the end of this course, you will be able to:

1. Write a **usable visual brief** with subject, light, lens, grade, and reject rules.
2. Prompt for **control**—photoreal vs illustration, camera/light, composition, helpful refs.
3. Lock **characters and products** across a stills set (seed vs describe).
4. **Edit, upscale, and batch** a small campaign without plastic artifacts.
5. Apply a **brand kit** and client-safe delivery (rights & likeness included).
6. Run an **Image OS**: prompt library, review rubric, handoff to video, ship a 6-image kit.

## Prerequisites

- Access to any modern image generation tool (chat or dedicated UI)
- Optional: a simple editor for crop/grade/export practice
- A practice brand brief (we use **Northstar Studio** throughout)
