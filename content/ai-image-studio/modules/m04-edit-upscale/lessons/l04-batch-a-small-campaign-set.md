## Teaching

### Batch with a checklist, not a binge

A Northstar mini-campaign batch:

1. Freeze style + character/product locks  
2. Shot list (hero, detail, lifestyle, social crop variants)  
3. Generate → set QA → inpaint/regen outliers  
4. Upscale protected masters  
5. Export pack per destination  
6. Delivery folder naming  

```text
BATCH — Northstar Fall Stills (6)
Locks: style + Nova sheet + bottle product
Shots: hero · detail lid · lifestyle table · pin motif · type-safe social · thumb
QA → finish → export pack → deliver
```

### Talk-over narration

*(Beat 1)* “Batching without locks multiplies chaos.”

*(Beat 2)* “Six coherent stills beat twenty orphans.”

### Worked micro-example

Shot list locked Monday; generate Tuesday; finish Wednesday; deliver one zip.

## Takeaway

Freeze locks, shoot a short list, QA the set, then finish and export as one pack.
