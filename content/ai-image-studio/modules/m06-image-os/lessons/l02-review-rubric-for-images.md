## Teaching

### Score before you ship

Northstar stills rubric (1–5 each):

| Pillar | Ask |
|--------|-----|
| Brief fit | Use case + subject read clear? |
| Consistency | Matches locks / set? |
| Technical | Mush, extras, edges, type space? |
| Brand | Palette, motif, type mood? |
| Rights | Likeness/NSFW/license OK? |

Ship threshold: no pillar below 3; rights must be 5.

```text
RUBRIC PASS if: all ≥3 and rights=5
Else: inpaint/regen with notes per pillar
```

### Talk-over narration

*(Beat 1)* “Opinions argue. Rubrics decide.”

*(Beat 2)* “Rights is pass/fail—never average it away.”

### Worked micro-example

Hero scores 5/4/3/5/5 → ship after light logo inpaint.

## Practice

Open `l02-interactive.html` and rewrite the vague prompt until the checker lights green.

## Takeaway

Review with five pillars; rights is binary-high—don't ship weak pillars.
