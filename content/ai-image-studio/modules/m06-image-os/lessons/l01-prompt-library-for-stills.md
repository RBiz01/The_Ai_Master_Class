## Teaching

### Library > chat archaeology

Store patterns, not one-off chat logs:

```text
LIBRARY ENTRY — product-hero-tabletop
Stack: photoreal
Locks: style + product
Camera/light: 85mm · soft window · amber rim
Composition: right third · left neg space
Do-nots: mush logo · extras · likeness
Vars: {sku} {surface} {prop?}
```

Tag by use case: hero, detail, lifestyle, social-safe, thumb-safe.

### Talk-over narration

*(Beat 1)* “If only one person can find the prompt, you don’t have a library.”

*(Beat 2)* “Variables keep locks stable while SKUs change.”

### Worked micro-example

Add `product-hero-tabletop` and `character-portrait-nova` entries to the Northstar library.

## Practice

Open `l01-interactive.html` and rewrite the vague prompt until the checker lights green.

## Takeaway

File named patterns with locks, camera/light, composition, do-nots, and variables.
