# Module 1 — Visual brief

**Slug:** `m01-visual-brief`
**Course:** AI Image Studio
**Lessons:** 4 · **Est. time:** ~60 minutes
**Status:** Fully built

---

## Goal

Write briefs that lock subject, light, lens, grade, and style—so stills are usable, not just pretty.

## Why this module ships first

Pretty one-offs waste budget. Module 1 installs a visual brief OS before you open any image model.
