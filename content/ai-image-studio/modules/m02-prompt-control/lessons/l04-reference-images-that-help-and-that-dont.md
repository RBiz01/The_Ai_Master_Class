## Teaching

### One job per reference

References help when each has a single job: **product shape**, **lighting recipe**, **palette**, or **pose/composition**. They hurt when they fight (photo + sticker art), imply a real celebrity, or smuggle NSFW/off-brand props.

Northstar rules:

- Max 2–3 refs; label each job  
- Prefer studio-owned or licensed stills; no real-person likeness targets  
- If refs conflict, the style lock wins  

```text
Refs:
1) product turntable plate — shape only
2) window-light tabletop — light only
Do not: celebrity faces, competitor logos, NSFW moodboards
```

### Talk-over narration

*(Beat 1)* “A pile of unrelated refs is a moodboard, not a control system.”

*(Beat 2)* “If the ref includes a recognizable person, stop—Northstar does not chase likeness.”

### Worked micro-example

**Bad:** 8 mixed Pinterest dumps + actor still.  
**Good:** product plate + lighting still, both labeled.
