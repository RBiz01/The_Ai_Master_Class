# Module 2 — Prompting for control

**Slug:** `m02-prompt-control`
**Course:** AI Image Studio
**Lessons:** 4 · **Est. time:** ~60 minutes
**Status:** Fully built

## Goal

Build model-agnostic prompt stacks for photoreal and illustration stills with camera, light, composition, and useful references.

## Why this module ships now

Survey courses skim prompting. Module 2 goes deep on control language that transfers across Midjourney/Flux/SD-style tools—stills only.
