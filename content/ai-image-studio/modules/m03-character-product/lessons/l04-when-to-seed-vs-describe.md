## Teaching

### Seed for continuity; describe for clarity

**Describe** when starting a new hero, changing wardrobe/SKU, or teaching a teammate. **Seed / reference-lock** when iterating within the same shot family and the tool supports it.

Northstar heuristic:

- New concept → describe from sheet/product lock  
- Same hero, small pose/light tweak → seed or image ref if available  
- Tool without reliable seed → stronger description + locked refs  
- Never seed toward a real-person photo  

```text
If new hero/SKU → DESCRIBE from locks
If same family tweak → SEED/REF if tool-stable
Else → describe + labeled refs
Never → real likeness seeds
```

### Talk-over narration

*(Beat 1)* “Seeds aren’t magic—unstable seeds waste a morning.”

*(Beat 2)* “When in doubt, describe from the sheet. Clarity ports across tools.”

### Worked micro-example

**Wrong:** seed off a celebrity still.  
**Right:** describe Nova’s sheet; optional product plate ref.
