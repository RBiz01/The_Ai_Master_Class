# Module 1 — Visual literacy for generative tools

**Slug:** `m01-visual-literacy`  
**Course:** Generative Media: Image & Video with AI  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Give learners a durable mental model for how image models interpret briefs—subject, scene, camera, and reference—so outputs stop feeling random.

## Why this module ships first

Style tricks fail if you cannot diagnose what the model misread. Module 1 is the operating system for every later shoot.

## Success criteria for the learner

- Can name subject, scene, camera, and style locks in a brief  
- Can translate a reference still into promptable language  
- Can spot common AI artifacts before client review  
- Can rewrite a mushy make-a-cool-image ask into a shootable brief
