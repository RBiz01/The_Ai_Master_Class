**Slug:** `m02-style-lighting-composition`  
**Course:** Generative Media: Image & Video with AI

**Status:** Fully built

---

## Goal

Teach repeatable style, lighting, and composition locks so Northstar looks stay on-brand across shoots.

## Why this module ships now

Visual literacy without lighting and composition control still produces lucky one-offs.

## Success criteria for the learner

- Can write a style anchor that survives regenerations  
- Can specify key / fill / rim lighting in prompt language  
- Can place subjects with intentional negative space  
- Can stack style + light + composition into one brandable prompt
