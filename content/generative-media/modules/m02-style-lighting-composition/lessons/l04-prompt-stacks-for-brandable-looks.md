# Lesson 2.4 — Prompt stacks for brandable looks

**Module:** Prompting for style, lighting, and composition  
**Duration:** ~6–8 min teaching + ~4 min interactive  
**Interactive:** `l04-interactive.html`

---

## Learning objective

Assemble subject + scene + camera + light + style + composition into one pasteable stack.

## Teaching

### The Northstar prompt stack

```
[SUBJECT]
[SCENE]
[CAMERA]
[LIGHTING]
[STYLE ANCHOR]
[COMPOSITION / NEG SPACE]
[NEGATIVES / DO-NOTS]
```

### Talk-over narration

*(Beat 1)* “Stacks beat vibes. Save them in your brand kit.”

## Worked micro-example

**Before**

> Premium lamp photo, nice vibe.

**After**

> Northstar brass desk lamp on walnut desk; morning office; 50mm 3/4 hero, shallow DOF; soft window key left + amber rim right; photoreal commercial, charcoal grounds, subtle grain; subject lower-left, open space upper-right; no neon, no people, no invented logos.
