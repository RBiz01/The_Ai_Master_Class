# Lesson 7.2 — Produce the hero stills

**Module:** Portfolio project sprint  
**Duration:** ~6–8 min teaching + ~4 min interactive  
**Interactive:** `l02-interactive.html`

## Learning objective

Generate and finish three on-brand hero stills using the full stack + cleanup.

## Teaching

### Sprint still plan

1. Product hero (lamp, neg space)  
2. Detail insert (brass texture)  
3. Context desk (optional Mira, original only)  

Run Modules 1–4 habits: stack → QA → inpaint → upscale → cleanup.

### Talk-over narration

*(Beat 1)* “Heroes earn the name after QA—not after the first generate.”
