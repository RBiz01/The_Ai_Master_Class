# Lesson 7.4 — Critique, package, and ship

**Module:** Portfolio project sprint  
**Duration:** ~6–8 min teaching + ~4 min interactive  
**Interactive:** `l04-interactive.html`

---

## Learning objective

Run a critique rubric, package the folder, and write a handoff note.

## Lesson video

![Lesson video](assets/l04-video.mp4)

**Video:** `assets/l04-video.mp4` — example/theme clip for this lesson.

## Teaching

### Rubric (1–5)

- On-brand palette & motif  
- Consistency across stills  
- Artifact QA  
- Caption clarity  
- Delivery completeness  

Handoff note: what shipped, tool list, license scope, open risks.

### Talk-over narration

*(Beat 1)* “Shipping is a critique plus a package—not a vibe.”

## Worked micro-example

**Before**

> Looks cool—send the Drive link.

**After**

> Rubric ≥4 on all axes; folder packaged; handoff note with license scope and tool list.

## Practice

Open `l04-interactive.html` and complete the drill until success criteria turn green.

## Takeaway

Critique → package → handoff note.
