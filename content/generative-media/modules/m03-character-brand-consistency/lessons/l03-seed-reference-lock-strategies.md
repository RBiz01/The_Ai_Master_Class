## Teaching

### Three locks

1. **Prompt lock** — same stack every time (baseline)  
2. **Seed lock** — same noise start when the tool allows  
3. **Reference lock** — image ref / character ref controls  

### When to use what

| Need | Prefer |
|------|--------|
| Same product, new angle | Prompt + seed explore |
| Same face across scenes | Character sheet + reference lock |
| Brand color forever | Brand kit in every prompt |

### Talk-over narration

*(Beat 1)* “Seeds aren’t magic—without a strong prompt, you lock in chaos.”
