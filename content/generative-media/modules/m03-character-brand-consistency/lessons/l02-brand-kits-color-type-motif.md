## Teaching

### Kit minimum viable

| Token | Northstar |
|-------|-----------|
| Primary | `#ec4899` pink |
| Accent | `#f59e0b` amber |
| Ground | `#0b0f19` |
| Motif | soft orb / gradient slash |
| Type vibe | geometric sans, confident |

Prompt cue: “Northstar brand palette pink-to-amber accents on charcoal ground, soft orb motif, no competing logos.”

### Talk-over narration

*(Beat 1)* “If color isn’t in the prompt, the model will invent a new brand.”

**After**
