## Teaching

### The Monday-morning problem

At **Acme Ops**, teams need answers grounded in the handbook—not confident guesses. This lesson locks a skill you’ll reuse all week.

### Beat 1

Start with 20–40 questions spanning escalations, vendors, go-live—include ‘should refuse’ cases.

### Beat 2

Each item: question, expected section IDs, must-include facts, must-not claims.

### Beat 3

Version the golden set with the handbook version date.
