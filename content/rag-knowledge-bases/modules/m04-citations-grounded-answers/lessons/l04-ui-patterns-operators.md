## Learning objective

Design answer UIs with source cards, confidence cues, and one-click open-in-handbook.

## Teaching

### The Monday-morning problem

At **Acme Ops**, teams need answers grounded in the handbook—not confident guesses. This lesson locks a skill you’ll reuse all week.

### Beat 1

Show answer + 2–4 source cards with section titles and version badges.

### Beat 2

Let operators expand the snippet; never hide the cite behind a mystery icon only.

### Beat 3

Feedback buttons (helpful / wrong source / missing) feed the eval loop.

### Talk-over narration (instructor VO)

*(Beat 1)*  
“Show answer + 2–4 source cards with section titles and version badges.”

*(Beat 2)*  
“Let operators expand the snippet; never hide the cite behind a mystery icon only.”

*(Beat 3)*  
“You’re done with this lesson when you can apply this on an Acme Ops handbook scenario without guessing.”

## Worked micro-example

**Before**

> Chat bubble with no sources and a green ‘confident’ badge always on.

**After**

> Answer panel + source cards (H-12, H-18) + ‘Open §3.1’ + thumbs + ‘report missing policy’.
