# Lesson 5.1 — Paste messy data → clean tables

**Module:** Spreadsheets, tables, and light analysis  
**Duration:** ~6–8 min teaching + ~4 min interactive  
**Interactive:** `l01-interactive.html`

---

## Learning objective

Normalize pasted Acme Ops rows into a clean table schema.

## What to do

1. Watch the **Lesson video** once for the visual hook.
2. Read **Teaching** (and the worked example) without rushing.
3. Open `l01-interactive.html` and follow its Instructions until you hit the success state (this locks in: Paste messy data → clean tables).
4. Rewrite or apply the idea once in your own words (one sentence is enough).
5. **You’re done when:** you can explain — in plain language — *Normalize pasted Acme Ops rows into a clean table schema.* and `l01-interactive.html` shows success.

## Teaching

### Dirty paste → schema

Provide target columns first: `Week | Vendor | Amount | Status`. Ask the model to normalize and flag bad rows.

### Talk-over narration

*(Beat 1)* “Schema before story. Clean table, then analysis.”

## Practice

Open `l01-interactive.html` and rewrite the vague prompt until the checker lights green.

## Takeaway

Name columns. Normalize. Flag garbage rows.
