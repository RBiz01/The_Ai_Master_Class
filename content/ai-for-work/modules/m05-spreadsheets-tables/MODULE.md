# Module 5 — Spreadsheets, tables, and light analysis

**Slug:** `m05-spreadsheets-tables`  
**Course:** AI for Work: ChatGPT & Claude  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Clean messy pasted data into tables, explain formulas in plain English, run light trend/outlier analysis, and ship exec one-pagers.

## Why this module ships here

Most work data arrives dirty. Module 5 makes ChatGPT/Claude your table co-pilot—not a replacement for your spreadsheet.

- Can turn a messy paste into a named-column markdown/CSV table  
- Can ask for formula explanations in plain English before applying

- Can draft an exec one-pager with one clear ask
