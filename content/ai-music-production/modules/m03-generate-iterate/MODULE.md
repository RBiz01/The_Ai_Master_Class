# Module 3 — Generate & iterate

**Slug:** `m03-generate-iterate`  
**Course:** AI Music Production  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Run first-pass generation that matches the brief, then extend/vary without losing the song—and decide vocals vs instrumental and regenerate vs edit.

## Why this module ships here

Iteration without a brief burns credits. Module 3 teaches controlled generation loops.
