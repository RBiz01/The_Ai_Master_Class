# Module 5 — Rights, credits, release

**Slug:** `m05-rights-release`  
**Course:** AI Music Production  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

## Goal

Claim authorship honestly, write credits/metadata/cover briefs, keep platform descriptions safe, and run a one-track release checklist.

## Why this module ships here

Shipping without rights clarity creates risk. Module 5 is the release gate.
