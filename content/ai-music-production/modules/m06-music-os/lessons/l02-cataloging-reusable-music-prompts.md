## Learning objective

Store reusable prompt blocks (brief, locks, arrangement, mix) in a searchable catalog.

## Teaching

### A catalog beats chat archaeology

Catalog fields: Name · Genre tags · Prompt block · Taste locks · Last used · Notes. Store model-agnostic blocks so switching tools doesn't rewrite your OS.

```text
Create 3 catalog entries for Northstar:
1) Dream-pop night drive
2) Upbeat indie bed for ads
3) Sparse piano underscore
Each: Name | Tags | Prompt block (4–6 lines) | Locks
```

### Talk-over narration

*(Beat 1)* “Name, tags, prompt block, locks—four fields minimum.”

*(Beat 2)* “Keep prompts model-agnostic.”

### Worked micro-example

Name: Neon Exit Bed · Tags: instrumental, ad, dream-pop · Locks: no lead vocal; leave VO space

## Practice

Open `l02-interactive.html` and rewrite the vague prompt until the checker lights green.

## Takeaway

Catalog reusable blocks so Monday you doesn't reinvent Friday's prompt.
