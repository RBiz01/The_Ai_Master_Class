**Level:** Beginner · **Duration:** 6 hours · **Lessons:** 24  
**Pacing:** ~1 hour per curriculum module × 6 modules  
**Gradient:** `#7c5cff` → `#00e5c0`  
**Product:** The Ai Master Class

## Who this is for

Operators, PMs, marketers, founders, and anyone who already uses ChatGPT, Claude, Gemini, or open models—and keeps rewriting the same vague ask until something sticks. You want **reproducible** outputs that ship Monday morning, not lucky one-offs.

No coding required. Model-agnostic patterns work across major assistants.

## Learning outcomes

By the end of this course, you will be able to:

1. Frame any task with **Goal · Context · Constraints · Format** so the model stops guessing.
2. Assign useful **roles**, hard **constraints**, and machine-readable **output formats**.
3. Design **few-shot exemplars** that teach tone, structure, and edge cases—not just “be nice.”
4. Use **chain-of-thought** and **task decomposition** when complexity rises.
5. Score outputs with **rubrics**, run cheap **eval loops**, and iterate without thrash.
6. Build a personal **prompt library** for email, research, meeting notes, and status updates.

### Module 1 — Foundations of clear instruction *(built)*

1. What makes a prompt clear  
2. The Goal · Context · Constraints · Format frame  
3. Specificity without overfitting  
4. Common failure modes  

### Module 2 — Roles, constraints, and output formats *(built)*

1. Role prompting that actually helps  
2. Hard vs soft constraints  
3. Tables, JSON, and checklists that parse  
4. Tone, audience, and brand voice locks  

### Module 3 — Few-shot & exemplars that stick *(built)*

1. Zero-shot vs few-shot: when to invest  
2. Writing exemplars that teach the pattern  
3. Contrast sets and near-miss examples  
4. Token budget and exemplar quality  

### Module 4 — Chain-of-thought and decomposition *(built)*

1. When to ask for reasoning (and when not to)  
2. Plan-then-answer patterns  
3. Decomposing multi-step work  
4. Self-checks and verification steps  

### Module 5 — Evaluation, rubrics, and iteration *(built)*

1. Rubrics beat vibes  
2. Building a tiny golden set  
3. Iterate without rewriting from scratch  
4. Model-agnostic eval habits  

### Module 6 — Prompt libraries for real workflows *(built)*

1. Cataloging prompts your team will reuse  
2. Email, notes, and status update kits  
3. Research & synthesis kits  
4. Versioning, handoff, and governance
