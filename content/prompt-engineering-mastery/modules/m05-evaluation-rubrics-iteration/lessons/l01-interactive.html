Pass/fail two Acme Ops outputs — vibes optional.

Instructions

  1. Read the rubric and both outputs.
  2. Mark each criterion Pass or Fail for Output A and Output B.

  4. Click Check scores.

Rubric (Acme Ops customer JSON)

1 Facts — no invented dates/ETAs 2 Format — JSON keys only, no essay wrapper 3 Policy — credit only if slip confirmed 4 Tone — calm, customer-ready

Output A

{"customer_message":"Thanks for checking AO-1042. Warehouse confirmed a short delay. We applied a 10% courtesy credit on your next invoice.","offer_applied":"10% courtesy credit on next invoice","needs_human_review":false}

Output B

Sure! As an AI I think your package arrives Friday for sure. {"customer_message":"It arrives Friday!","offer_applied":"full refund","needs_human_review":false}

A is clean → ship. B invents Friday (Facts fail), wraps with essay (Format fail), full refund not allowed (Policy fail).

You're done when

  • A → Ship
  • B Facts → Fail
  • B Format → Fail
  • B Policy → Fail
