# Module 5 — Evaluation, rubrics, and iteration

**Slug:** `m05-evaluation-rubrics-iteration`  
**Course:** Prompt Engineering Mastery  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Replace “looks good to me” with lightweight rubrics, tiny golden sets, and disciplined revision loops. Learners score outputs against criteria, keep a pocket eval set for Acme Ops workflows, and iterate prompts without starting from a blank page—model-agnostic habits that survive tool churn.

## Why this module ships fifth

Decomposition gets you structure. Evaluation keeps you honest. Without a rubric, every rewrite is vibes—and thrash returns by Wednesday.

## Success criteria for the learner

- Can write a 3–5 criterion rubric that catches real Acme Ops failures  
- Can assemble a tiny golden set (happy path + edge + cliff)  
- Can patch a prompt without blank-page thrash  
- Can keep eval habits model-agnostic (prompt vs process decisions)
