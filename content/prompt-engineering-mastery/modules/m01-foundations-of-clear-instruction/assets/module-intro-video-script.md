## Talk-over (narration)

*(0:00–0:25)*  
Welcome to Module 1 of **Prompt Engineering Mastery** on The Ai Master Class. Before roles, few-shot, or chain-of-thought, we fix the boring problem that breaks everything else: **unclear instructions**.

*(0:25–0:55)*  
At fictional Acme Ops, “summarize the emails” produces a different answer every day—not because the model is random for sport, but because the prompt leaves decisions open. Audience? Scope? Shape? The model invents them.

*(0:55–1:40)*  
In this hour you’ll learn four moves. Spot vagueness fast. Install the **Goal · Context · Constraints · Format** frame. Dial specificity without overfitting. Diagnose the four failure modes: missing goal, hidden context, conflicting constraints, and format drift.

*(1:40–2:30)*  
You’ll watch a live rewrite of a bad email-summary prompt, study a labeled diagram of the clear-prompt frame, and complete four interactive drills with explicit success criteria. Expect roughly one hour: intro, four lessons with practice, and a demo.

*(2:30–3:15)*  
Success looks like this: you can take a mushy ask, fill GCCF, and ship a brief another teammate could run without pinging you. Let’s make prompts that behave the same on Monday as they did on Friday.

*(3:15–3:45)*  
Open Lesson 1 — What makes a prompt clear — when you’re ready. Headphones on; editor ready.
