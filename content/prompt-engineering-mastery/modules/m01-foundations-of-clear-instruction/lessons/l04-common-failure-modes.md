# Lesson 1.4 — Common failure modes

**Module:** Foundations of clear instruction

## Learning objective

Diagnose the four most common clarity failures and apply a targeted fix instead of rewriting from scratch.

## Teaching

### Failure mode cheat sheet

| Mode | Symptom | Fix |
|------|---------|-----|
| **1. Missing goal** | Beautiful prose, wrong job | Write one sentence: “Done means ___.” |
| **2. Hidden context** | Model invents dates, roles, systems | Paste facts; label them CONTEXT |
| **3. Conflicting constraints** | “Be brief” + “cover everything in depth” | Pick a priority; drop or sequence the rest |
| **4. Format drift** | Asked for bullets; got an essay | Restate FORMAT; add a one-line example skeleton |

### Mode 1 — Missing goal

> “Thoughts on this?”

Thoughts aren’t a deliverable. Replace with an observable outcome: decision memo, risk list, reply draft.

### Mode 2 — Hidden context

You know the portal go-live is Friday. The model doesn’t. Unstated context becomes confident fiction. Always surface: timeframe, audience, systems, stakes.

### Mode 3 — Conflicting constraints

> “Keep it under 50 words and include a full competitive analysis.”

Models will compromise unpredictably. Explicit priority beats silent conflict:

> “Priority: ≤50 words. If analysis won’t fit, give top 2 competitive risks only.”

### Mode 4 — Format drift

If you need a table, say `markdown table with columns A | B | C`. If you need JSON, show a tiny schema. Format is not implied by vibe.

### Debug ritual (60 seconds)

1. Underline the **goal** sentence—if you can’t, Mode 1.  
2. List facts the model must know—if they’re only in your head, Mode 2.  
3. Scan for opposing limits—if both stay, Mode 3.  
4. Ask: could this arrive as an essay when you need a checklist?—Mode 4.

### Talk-over narration

*(Beat 1)*  
“Don’t rage-rewrite. Diagnose. Four modes cover most clarity failures.”

*(Beat 2)*  
“Missing goal, hidden context, conflicting constraints, format drift. Name it, then patch the slot.”

*(Beat 3)*  
“In the interactive, you’ll match broken prompts to failure modes and apply the right fix.”
