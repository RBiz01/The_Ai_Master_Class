# Module 6 — Prompt libraries for real workflows

**Slug:** `m06-prompt-libraries-workflows`  
**Course:** Prompt Engineering Mastery  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Package everything into a reusable library: naming, versioning, and handoff so a team can share prompts without chaos. Ship starter kits for email, meeting notes, status updates, and research synthesis. Close with light governance—what to store, what to retire, what never to paste.

## Why this module ships last

Modules 1–5 taught you to write, shape, exemplify, decompose, and evaluate. Module 6 makes the wins **findable next Monday**—a personal (or team) library that ships without archaeology.
