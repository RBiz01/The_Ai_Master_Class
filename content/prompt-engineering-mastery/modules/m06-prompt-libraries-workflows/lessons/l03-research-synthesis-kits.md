## Learning objective

Build a research synthesis kit that separates **claims**, **sources**, and **confidence**—so Acme Ops never ships a rumor as a fact.

## Teaching

### Synthesis kit essentials

| Slot | Rule |
|------|------|
| GOAL | Question to answer |
| SOURCES | Paste or list only; no silent web inventing |
| FORMAT | Claim · Evidence · Confidence (High/Med/Low) |
| CONSTRAINTS | Flag gaps; never invent citations |

### Confidence language

- **High** — multiple sources agree, dates clear  
- **Med** — single source or partial overlap  
- **Low** — inference; needs human check  

### Anti-patterns

- “According to studies…” with no study.  
- Mixing competitor rumor with confirmed changelog.  
- One mega-paragraph with no claim boundaries.

### Talk-over narration

*(Beat 1)*  
“Research kits earn their keep when confidence is visible.”

*(Beat 2)*  
“At Acme Ops, competitor notes must show Claim / Evidence / Confidence or they don’t leave draft.”

*(Beat 3)*  
“In the drill, you’ll assemble a synthesis FORMAT that forces source discipline.”

## Worked micro-example

```text
## Claim
Wave-2 docs still draft
## Evidence
Internal status paste 2026-09-01
## Confidence
High
```
