Sort hard vs soft constraints

Label musts, preferences, and a priority line for Acme Ops.

Instructions

  1. Read the mixed constraint list.
  2. Classify items A–D as Hard or Soft.
  3. Write a PRIORITY line that says what wins if space is tight.
  4. Click Check sort.

Mixed constraints (Acme Ops standup digest)

A. Max 5 bullets B. Prefer plain words over jargon C. Mark go-live threats with the word BLOCKER D. Lead with the highest-severity item when possible E. No speculation beyond the pasted emails

Classify A–D (E is always Hard — already known)

Hard = break-the-build (limits, labels, no speculation). Soft = “prefer / when possible.” Priority should keep BLOCKERs over completeness or WATCH items.

You're done when

  • A → Hard
  • B → Soft
  • C → Hard
  • D → Soft
  • Priority keeps BLOCKERs (or must-haves) over completeness
