**Slug:** `m02-roles-constraints-output-formats`  
**Course:** Prompt Engineering Mastery  
**Lessons:** 4 · **Est. time:** ~60 minutes  
**Status:** Fully built

---

## Goal

Teach learners when role prompting helps, how to separate hard vs soft constraints, how to demand parseable shapes (tables, JSON, checklists), and how to lock tone/audience without cartoon personas. Builds directly on Module 1’s GCCF frame so Role and Format become deliberate slots—not vibes.

## Why this module ships second

Module 1 made instructions clear. Module 2 makes them **controllable**: who the model acts as, what it must never violate, and what shape leaves the chat ready for a human or a tool.

## Success criteria for the learner

- Can write a role that adds expertise or perspective without cartoon cosplay  
- Can separate hard constraints (must / must-not) from soft preferences  
- Can specify tables, JSON schemas, or checklists that a teammate or script can parse  
- Can lock tone, audience, and brand voice without overfitting to one person’s email style
