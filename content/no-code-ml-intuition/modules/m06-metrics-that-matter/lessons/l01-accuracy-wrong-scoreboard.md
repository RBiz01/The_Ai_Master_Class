## Teaching

### The 99% trap

If 99% of tickets are routine, always predicting routine is 99% accurate — and useless for the 1% incidents.

### When accuracy misleads

- Rare but costly positives
- Uneven class mix
- Changing base rates

### Talk-over narration

*(Beat 1)* Accuracy loves the majority class.
*(Beat 2)* Ask what errors cost.
*(Beat 3)* Lead with the metric tied to the decision.
