## Teaching

### One screen, five elements

1. Primary business metric with threshold
2. Volume processed this week
3. FP/FN counts or costed estimates
4. Drift / agreement sample
5. Decision: hold / tune / kill

### Anti-patterns

Sparkline forests. Unlabeled axes. Metrics with no owner.

### Talk-over narration

*(Beat 1)* Executives buy decisions, not dashboards.
*(Beat 2)* Thresholds turn charts into actions.
*(Beat 3)* If nothing would change the plan, delete the widget.
