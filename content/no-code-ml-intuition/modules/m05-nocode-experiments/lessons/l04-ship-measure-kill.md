## Learning objective

## Teaching

### Decision card

- **Ship** if holdout clears threshold and errors are affordable
- **Iterate** if close and fixable
- **Kill** if baseline wins or error cost exceeds value

### After ship

Weekly: sample 20 predictions, human-review, watch drift.

### Talk-over narration

*(Beat 1)* Shipping is a bet with a review date.
*(Beat 2)* Kill criteria protect reputation.
*(Beat 3)* Measurement is part of the product.
