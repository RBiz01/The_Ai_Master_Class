# Lesson 5.1 — Pick a question before you pick a tool

**Module:** No-code experiments you can ship  
**Duration:** ~6–8 min teaching + ~4–8 min interactive  
**Interactive:** `l01-interactive.html`

---

## Learning objective

Write a falsifiable ML question first.

![Lesson video](assets/l01-video.mp4)

**Video:** `assets/l01-video.mp4` — example/theme clip for this lesson.

## Teaching

### Question template

> For [who], will [model/task] improve [metric] vs [baseline] on [slice] within [timebox]?

Bad: Let's try the new AutoML.
Good: For Acme Ops L1 agents, will a triage classifier cut median route-time 20% vs keyword rules on Sev-3 tickets in 5 days?

### Talk-over narration

*(Beat 1)* Write the question before opening a tool.
*(Beat 2)* No baseline means no claimed win.
*(Beat 3)* Falsifiable beats fashionable.
