## Teaching

### 5-day skeleton (Acme Ops)

| Day | Focus |
|-----|-------|
| 1 | Question, baseline, success metric, kill rule |
| 2 | Data extract + label audit |
| 3 | Split + first model |
| 4 | Error analysis + one iteration |
| 5 | Test once + ship/kill memo |

### Owners

Name a decision owner. Experiments without owners become slideware.

### Talk-over narration

*(Beat 1)* One week. One metric. One owner.
*(Beat 2)* Day 5 is a decision, not a new idea.
*(Beat 3)* Write the kill rule while optimism is high.
