## Teaching

### Jobs to tool types

| Job | Tool flavor |
|-----|-------------|
| Tabular classify/regress | AutoML / spreadsheet ML |
| Text classify | No-code classifiers |
| Find similar docs | Embedding search UIs |
| Extract fields | LLM workflows with schema |

### Selection rules

- Match data shape first
- Prefer tools that show holdout metrics
- Exportability and audit logs beat flashy demos

### Talk-over narration

*(Beat 1)* Pick tools for the job, not the homepage hero.
*(Beat 2)* Hidden splits mean entertainment scores.
*(Beat 3)* Export paths are a buy decision.
