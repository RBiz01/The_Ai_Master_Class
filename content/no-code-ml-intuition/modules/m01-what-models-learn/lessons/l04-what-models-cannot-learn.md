## Teaching

### Hard limits

1. **No causal proof** — correlation is not causation.
2. **No ethics module** — biased labels become biased predictions.
3. **No missing-signal recovery** — absent features stay absent.
4. **No free lunch from bad labels**.

### Acme Ops caution

Predicting escalation from text that already contains the escalation tag is leakage, not intelligence.

### Talk-over narration

*(Beat 1)* Models amplify what you measure.
*(Beat 2)* AutoML cannot conjure missing signal.
*(Beat 3)* Know the limits before you ship the demo.
