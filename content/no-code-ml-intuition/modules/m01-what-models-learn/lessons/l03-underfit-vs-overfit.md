## Teaching

### Two ways to be wrong

| Mode | Demo symptom | Fix direction |
|------|--------------|---------------|
| Underfit | Train and test mediocre | Richer features |
| Overfit | Train amazing; test collapses | Cleaner data, simpler model, better validation |

### Northstar example

A 99% train score on 80 briefs that memorized designer names collapses on a new designer.

### Talk-over narration

*(Beat 1)* Great train + sad test = memorized worksheet.
*(Beat 2)* Boring everywhere = underfit.
*(Beat 3)* Always ask about rows never seen.
