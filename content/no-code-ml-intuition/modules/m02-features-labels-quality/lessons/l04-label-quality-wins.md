## Teaching

### The uncomfortable ROI

Relabeling 200 rows often beats a new AutoML seat.

### Label failure modes

- Inconsistent definitions
- Majority class stamped by default
- Soft labels forced hard
- Concept drift across years

### Northstar ritual

Two producers label 50 briefs. Disagreements rewrite the definition — not the model.

### Talk-over narration

*(Beat 1)* Label quality is the ceiling.
*(Beat 2)* Human agreement is a feature.
*(Beat 3)* Fix labels before algorithms.
