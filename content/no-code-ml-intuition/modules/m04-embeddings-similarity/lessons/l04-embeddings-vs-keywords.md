## Teaching

### Choose the right search

| Situation | Prefer |
|-----------|--------|
| Synonyms / paraphrases | Embeddings |
| Exact SKUs, error codes | Keywords / filters |
| Hybrid needs | Both |

### Failure story

Pure vector search buried the brief containing AO-1042. Keyword filter caught it. Hybrid won.

### Talk-over narration

*(Beat 1)* Embeddings love paraphrase. Keywords love exactness.
*(Beat 2)* Rare tokens need lexical search.
*(Beat 3)* Hybrid is often the Monday default.
