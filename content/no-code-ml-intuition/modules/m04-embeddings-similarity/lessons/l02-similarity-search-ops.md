## Teaching

### Ops uses that ship

Northstar: find past briefs like this one; surface similar objections; dedupe assets.
Acme Ops: related tickets; nearest policies.

### Recipe

1. Embed the corpus
2. Embed the query
3. Return top-k neighbors
4. Human (or LLM) reads passages

### Talk-over narration

*(Beat 1)* Similarity search means show neighbors.
*(Beat 2)* Retrieval quality beats generator poetry for ops trust.
*(Beat 3)* Log useful neighbors — that is your eval set.
